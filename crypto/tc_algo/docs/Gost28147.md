# GOST 28147

GOST 28147-89 takes an S-box besides its key: eight tables of 16 values each, 128 bytes, which the
standard left to each user to choose. Russian standards and CryptoPro name a few of them by OID.
The `gost28147` feature has the rows; see [Block ciphers](BlockCipher.md#gost28147) for their
names.

GOST 28147 is legacy, with a block of 8 bytes: use it only to read data that already uses it, or
where a Russian standard requires it.

## A key alone

A `KeyOwned`, or a `KeyWithIvOwned` with an IV, takes the default S-box, as Bouncy Castle gives a
`KeyParameter`.

## Another S-box

`Gost28147ParamsOwned::with_s_box` sets it, and `tc_algo::params::gost28147_s_box` has the named
tables of `tc_gost28147`, such as `E_A`, CryptoPro's set A. In ECB the params go to the row as they
are; in the modes with an IV they go with the IV in a `ParamsWithIvOwned`, as Bouncy Castle's
`ParametersWithIV(ParametersWithSBox(key, sbox), iv)`.

```rust
use tc_algo::params::{Gost28147ParamsOwned, ParamsWithIvOwned, gost28147_s_box};
use tc_algo::{AlgoBuilder, AlgoError, DefaultAlgoBuilder};

fn main() -> Result<(), AlgoError> {
    let algo = DefaultAlgoBuilder::default().build();
    let name = "GOST28147/CBC/PKCS7PADDING";

    // A 32-byte key with CryptoPro's set A, and an IV of one block, 8 bytes
    let gost = Gost28147ParamsOwned::with_s_box(key.to_vec(), gost28147_s_box::E_A.to_vec());
    let params = ParamsWithIvOwned::new(gost, iv.to_vec());

    let ciphertext = algo.cipher().encrypt_by_name(name, &params, message)?;
    Ok(())
}
```

`Gost28147ParamsOwned::new(key)` takes the default S-box, as a `KeyOwned` does.

| Rows | Params |
|---|---|
| ECB | `KeyOwned` or `Gost28147ParamsOwned` |
| CBC, CFB, OFB, CTR, GOFB, OPENPGPCFB | `KeyWithIvOwned` or `ParamsWithIvOwned<Gost28147ParamsOwned>` |

The IV is one block, 8 bytes, in every mode but CTR, which takes it as `tc_block_modes` does. The
key and the S-box are checked when the row is initialized, not when the params are built; an S-box
of another length than 128 bytes is `InvalidParams`.

GOST's own counter mode, GCTR, which Bouncy Castle calls GOFB, is `GOST28147/GOFB/NOPADDING`, and
takes the same params as CTR. GOST's MAC is not a cipher, and is not among these rows.
