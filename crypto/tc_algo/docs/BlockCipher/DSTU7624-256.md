# DSTU7624-256

The `dstu7624` feature has the rows. A block of 32 bytes and a key of 32 or 64; Kalyna, the block
cipher of Ukraine, of DSTU 7624:2014. Bouncy Castle has the engine but does not name it in
`CipherUtilities`, so the name is this crate's, after the block in bits, and has no OID.

P1: The modes with an IV accept `KeyWithIvOwned`, `ParamsWithIvOwned<KeyOwned>`, or
`ParamsWithIvOwned` holding a `Box<dyn Params>` or `Arc<dyn Params>` containing `KeyOwned`. Use the
`KEY` key generator with a `KeyLength` of 32 or 64 bytes to obtain a `KeyOwned`. The `Box` goes with
one message. An `Arc` lets one key serve many messages, each with a fresh IV, without copying the
key.
