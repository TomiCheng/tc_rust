# RC5-64

The `rc-cipher` feature has the rows. RC5 with 64-bit words: a block of 16 bytes and a key of up to
255
bytes, with 12 rounds, or the number RC5's own params give; see [RC5](../Rc5.md).

P1: The modes with an IV accept a bare key with 12 rounds as `KeyWithIvOwned` or
`ParamsWithIvOwned<KeyOwned>`. Use `ParamsWithIvOwned<Rc5ParamsOwned>` to supply the round count. A
`ParamsWithIvOwned` can also hold a `Box<dyn Params>` or `Arc<dyn Params>` containing either
`KeyOwned` or `Rc5ParamsOwned`. The `RC5-64` key generator returns `Rc5ParamsOwned`. The `Box` goes
with one message. An `Arc` lets one key serve many messages, each with a fresh IV, without copying
the key.
