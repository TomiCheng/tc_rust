# GOST28147

The `gost28147` feature has the rows. GOST 28147-89: a block of 8 bytes and a key of 32 bytes, also
named `GOST` and `GOST-28147`. A plain key takes the default S-box, as Bouncy Castle gives a
`KeyParameter`, and GOST 28147's own params take another; see [GOST 28147](../Gost28147.md).

The OID is CryptoPro's `id-Gost28147-89`, which Bouncy Castle gives to CBC with PKCS#7 padding, and
so do these rows; in CryptoPro's own formats it names GOST 28147 in its CFB mode, with the S-box in
its parameters.

P1: The modes with an IV accept a bare key with the default S-box as `KeyWithIvOwned` or
`ParamsWithIvOwned<KeyOwned>`. Use `ParamsWithIvOwned<Gost28147ParamsOwned>` to supply an S-box. A
`ParamsWithIvOwned` can also hold a `Box<dyn Params>` or `Arc<dyn Params>` containing either
`KeyOwned` or `Gost28147ParamsOwned`. The `GOST28147` key generator returns `Gost28147ParamsOwned`.
The `Box` goes with one message. An `Arc` lets one key serve many messages, each with a fresh IV,
without copying the key.
