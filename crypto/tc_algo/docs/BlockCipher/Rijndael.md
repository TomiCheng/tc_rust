# Rijndael

The `misc-block-cipher` feature has the rows. Rijndael with a block of 16 bytes, as Bouncy Castle's
CipherUtilities builds it: the same cipher as AES, under the name it had before it became AES. A key
of 16, 24 or 32 bytes.

For new data, take `AES`, which is constant time where `tc_aes` can be.

P1: The modes with an IV accept `KeyWithIvOwned`, `ParamsWithIvOwned<KeyOwned>`, or
`ParamsWithIvOwned` holding a `Box<dyn Params>` or `Arc<dyn Params>` containing `KeyOwned`.
`RIJNDAEL` generates a `KeyOwned`. The `Box` goes with one message. An `Arc` lets one key serve many
messages, each with a fresh IV, without copying the key.
