# Threefish-1024

The `threefish` feature has the rows. A block and a key of 128 bytes, and a tweak of 16 bytes:
a plain key takes a tweak of zeros, as Bouncy Castle gives a `KeyParameter`, and Threefish's own
params take another; see [Threefish](../Key/ThreefishParamsOwned.md).

P1: The modes with an IV accept a bare key with an all-zero tweak as `KeyWithIvOwned` or
`ParamsWithIvOwned<KeyOwned>`. Use `ParamsWithIvOwned<ThreefishParamsOwned>` to supply a tweak. A
`ParamsWithIvOwned` can also hold a `Box<dyn Params>` or `Arc<dyn Params>` containing either
`KeyOwned` or `ThreefishParamsOwned`. The `THREEFISH-1024` key generator returns
`ThreefishParamsOwned`. The `Box` goes with one message. An `Arc` lets one key serve many messages,
each with a fresh IV, without copying the key.
