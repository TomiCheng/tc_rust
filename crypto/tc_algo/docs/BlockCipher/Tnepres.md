# Tnepres

The `serpent` feature has the rows. Serpent in the byte- and word-reversed form of its AES
submission, which Bouncy Castle's first Serpent used, with the key of Serpent. It is for data made
in that form; new data takes `SERPENT`.

P1: The modes with an IV accept `KeyWithIvOwned`, `ParamsWithIvOwned<KeyOwned>`, or
`ParamsWithIvOwned` holding a `Box<dyn Params>` or `Arc<dyn Params>` containing `KeyOwned`.
`TNEPRES` generates a `KeyOwned`. The `Box` goes with one message. An `Arc` lets one key serve many
messages, each with a fresh IV, without copying the key.
